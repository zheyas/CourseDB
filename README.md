
# Проект для работы с API hh.ru и базой данных

## Описание

Данный проект реализует взаимодействие с API hh.ru, чтобы получать данные о компаниях и их вакансиях. Эти данные затем сохраняются в базе данных, что позволяет проводить дальнейший анализ.

## Требования

- Python 3.x
- Установленные библиотеки:
  - `requests`
  - `psycopg2` (для работы с PostgreSQL)
  
## Установка

1. Клонируйте репозиторий или скачайте архив проекта.
2. Установите необходимые зависимости:
   pip install requests psycopg2
   
   

## Использование

1. Настройте параметры подключения к вашей базе данных в `main.py`: python
   db_name = 'Course3'
   user = 'postgres'
   password = '123456789'

   

2. Запустите `main.py`: python main.py


3. Введите ключевое слово, когда программа запросит его, для поиска компаний через API hh.ru.

## Структура проекта

- `api_handler.py`: Модуль для работы с API hh.ru.
- `db_handler.py`: Модуль для взаимодействия с базой данных PostgreSQL.
- `main.py`: Основной скрипт, который запускает весь процесс.

## Функциональность

- Поиск компаний через API hh.ru по введенному ключевому слову.
- Получение данных о вакансиях компаний.
- Сохранение данных о компаниях и вакансиях в базу данных.
- Вывод различных аналитических данных, таких как количество вакансий и средняя зарплата.

## Примечания

- Убедитесь, что у вас есть интернет-соединение для взаимодействия с API hh.ru.
- Проверьте, чтобы PostgreSQL сервер был настроен и запускался перед использованием этого проекта.
- Все изменения в конфигурации (например, параметры БД) следует вносить до запуска `main.py`.
